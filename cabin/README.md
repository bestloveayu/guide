# 虛擬機艙編輯器（空服員訓練模擬）

這是一個純前端的網頁應用，不需要安裝任何套件，Three.js 已放在 `vendor/` 中。玩家扮演空服員，在虛擬機艙中完成整趟航班的標準作業流程，並處理旅客需求。

## 啟動

ES Module 需要透過 HTTP 開啟，直接雙擊 `index.html` 無法使用。在專案根目錄執行：

```bash
python3 -m http.server 8080
```

然後開啟 <http://localhost:8080/cabin/>。也可以放在你現有的伺服器（例如 3012 埠）的靜態目錄下。

## 功能總覽

| 區塊 | 內容 |
| --- | --- |
| 機艙編輯 | 內建 A321、B787-9、ATR 72 三個範本，可建立多個機艙並切換。可點選、框選或整排選取座位，然後移除或復原座位、刪除整排、在後方插入一排（後方的排號與設施會自動順移）、變更艙等，也可以放置或拖曳艙門、廚房、洗手間、組員座椅等設施。 |
| 平面圖匯入 | 先匯入機型平面圖當作底圖，對齊並調整比例。用「框選產生座位」框出座位區，輸入座位配置（如 `ABC-DEF`、`ABC-DEFG-HJK`）和排號，系統會自動排出座位並留出走道，動線（A* 尋路網格）也會依據新的佈局自動計算。 |
| 旅客 | 可在座位上放置旅客，類型包括 VIP、年長、兒童、特殊餐、行動不便、飛行焦慮、飲酒過量、身體不適，並可設定心情與備註，也能依載客率隨機填滿。 |
| 任務 / 劇情 | 任務類型有：對話、前往定點、客艙巡查、廣播、就座、組員管理。每個任務可設定觸發階段與秒數、優先順序、時間限制、對象、回應選項（分數與心情變化）以及最低職級。劇本則可設定航班、航線、開場劇情和 NPC 名稱，並可匯出或匯入 JSON。 |
| 物件互動 | 靠近即可操作（按 E、點畫面按鈕或直接點 3D 物件）：開關行李櫃（櫃內有行李）、洗手間門並檢查洗手間、坐上組員座椅／繫上或解開安全帶／站起、拉下氧氣面罩、進出組員休息室（上下舖）、以內線請求進入駕駛艙。 |
| 規範與違規 | 起降期間離開座椅或解開安全帶、滑行與起降期間開啟行李櫃、起降開始時行李櫃或洗手間門未關、亂流中開行李櫃、無故拉下氧氣面罩、滑行起降中提供餐飲、對酒醉旅客續酒，都會記為違規並列在結算畫面。 |
| 駕駛艙 | 平時上鎖；依程序以內線說明來意，巡航時機長才會開門，起降等關鍵階段一律不開。無故要求或強行要求會被警告，堅持進入會由空安人員制止並逮捕，航班直接失敗。 |
| 旅客交談 | 走到任何旅客旁邊都能交談，選項依旅客類型、飛行階段、安全帶燈而不同；會影響滿意度與耐心。短時間內重複打擾會降低耐心，有待處理需求時耐心會隨時間下降。 |
| 飛行流程 | 登機 → 關門推出 → 滑行 → 起飛 → 爬升 → 巡航 → 下降 → 落地 → 下機。會模擬高度、速度、俯仰、震動、亂流、安全帶燈、客艙燈光、窗外跑道與雲層。起降時必須回到組員座椅就座。 |
| 視角 | 平面圖（2D）、3D 預設（環繞）、第一人稱。第一人稱按住滑鼠左鍵拖曳轉動視角（不鎖定游標），WASD 移動；直接點旅客即可走過去並開始對話，點地板可走到該處。 |
| 廣播 | 可用麥克風進行語音辨識（Chrome / Edge），也可以直接輸入文字。系統以「文字相似度＋關鍵詞」評分，由學姊或座艙長講評並可用語音唸出。勾選背誦模式會隱藏講稿並加分。 |
| 生涯 | 每趟航班會依任務品質、旅客滿意度、優先順序判斷和安全表現獲得經驗值。職級依序為：見習空服員 → 空服員 → 資深空服員 → 座艙長。晉升後會解鎖新任務。 |
| 座艙長 | 可以把任務指派給能力不同的組員，並處理組員衝突、向機長報告客艙準備完成。 |
| 角色 | 可自訂航空公司名稱、制服（外套、裙或褲、絲巾、襯衫、帽子）、髮色與膚色，顏色也會套用到機身塗裝。 |

## 本機測試版（不需 AI 金鑰）

不需要安裝套件，只要有 Node.js 18 以上即可。

- Windows：雙擊 `cabin/start-test.bat`
- Mac：雙擊 `cabin/start-test.command`
- 或在 repo 根目錄執行 `node cabin/server/test-server.js`

啟動後開啟 <http://localhost:3013/cabin/>。接著進入「設定」，按「使用本機測試伺服器」，再按「測試連線」，看到 ✅ 就可以開始飛行並練習廣播。

測試伺服器用「模擬 AI」評分：依文字比對和關鍵詞算出分數，再用學姊或座艙長的口吻產生講評，終端機會印出每次評分的紀錄。它的請求與回應格式和正式版完全相同，之後接上 3012 的真正 AI 時，只要在設定改成「填入 3012 預設網址」即可。如果 3013 埠被占用，可以改用其他埠：`PORT=3014 node cabin/server/test-server.js`。

## 接上 3012 AI 伺服器評分廣播

`server/announcement-judge.js` 是一個可直接掛到 Express 伺服器的路由，會沿用伺服器原本呼叫 AI 的方式與 API 金鑰。

1. 把 `server/announcement-judge.js` 複製到 3012 伺服器的專案資料夾。
2. 在伺服器主程式（`app.listen(3012)` 之前）加入：

   ```js
   app.use(express.json()); // 已有就不用重複
   const mountAnnouncementJudge = require('./announcement-judge');
   mountAnnouncementJudge(app, askAI);
   ```

   `askAI` 是一個函式：輸入提示文字，回傳 AI 的回覆文字。請用伺服器現有呼叫 AI 的程式包裝，例如：

   ```js
   // OpenAI
   const askAI = async (prompt) => (await openai.chat.completions.create({
     model: 'gpt-4o-mini', messages: [{ role: 'user', content: prompt }] })).choices[0].message.content;
   // Anthropic Claude
   const askAI = async (prompt) => (await anthropic.messages.create({
     model: 'claude-haiku-4-5', max_tokens: 400, messages: [{ role: 'user', content: prompt }] })).content[0].text;
   ```

3. 重新啟動 3012 伺服器。
4. 開啟機艙頁面，進入「設定」，按「填入 3012 預設網址」，再按「測試連線」，看到 ✅ 就代表接上了。
5. 之後每次廣播都會由 AI 評分，講評上會標示「AI 評分」。AI 連不上時會自動改用本機評分。

路由已處理跨來源（CORS），所以機艙頁面用 8080 開、AI 伺服器在 3012 也能使用。如果把 `cabin/` 放進 3012 伺服器的靜態目錄（例如 `app.use(express.static(...))`），網址填 `/api/judge-announcement` 即可。

端點格式：`POST /api/judge-announcement`，請求為 `{ reference, transcript, keywords, speaker, rank, localScore }`，回應為 `{ score: 0-100, feedback }`。

## 機型規格 JSON（匯入用）

除了匯出的完整機艙 JSON，也可以匯入「規格」格式。規格中的 `segments` 會沿著機身由前往後排列：

```json
{
  "name": "自訂 A320",
  "width": 3.7,
  "segments": [
    { "type": "fixtures", "len": 2.4, "items": [["cockpit", "F", 0, 2.2, 3.7, "駕駛艙"]] },
    { "type": "fixtures", "len": 2.6, "items": [["door", "L", 0.2, 0.9, 0.25, "L1"], ["galley", "R", 1.2, 1.3, 0.9, "前廚房"], ["jumpseat", "L", 1.2, 0.5, 0.5, "L1 組員座"]] },
    { "type": "seats", "cls": "Y", "from": 1, "to": 30, "skip": [13], "pattern": "ABC-DEF", "pitch": 0.79, "seatW": 0.46 }
  ]
}
```

`items` 中每一項的欄位依序為：`[類型, 位置 L/R/C/F（左/右/中/全寬）, 段內起點(m), 長(m), 寬(m), 標籤]`。任務的 `target.fixture` 可以填標籤（例如 `L1`），也可以填類型（例如 `galley`，代表最近的一個廚房）。

## 檔案結構

```
cabin/
  index.html  cabin.css
  js/data.js      飛行階段、職級、旅客類型、機型範本、預設劇本與廣播詞
  js/layout.js    由規格產生座位、編輯操作、框選產生、尋路網格（A*）
  js/sim.js       飛行模擬：任務佇列、優先順序判定、移動、組員分派、結算
  js/speech.js    語音辨識、廣播評分、AI 端點、語音回饋
  js/view2d.js    2D 平面圖編輯器與俯視圖
  js/view3d.js    Three.js 3D 機艙、角色模型、起降環境
  js/app.js       介面面板與整體流程
  vendor/         Three.js r160（MIT）
```

資料儲存在瀏覽器的 localStorage，可在「設定」中匯出或匯入全部資料。

## 後續可擴充

- 平面圖自動辨識：目前需要手動框選座位區，之後可以加入影像辨識，自動找出座位方塊與艙門位置。
- 更多階段事件：例如緊急撤離、失壓、機上火警，以及免稅品販售。
- 多人或教官模式：教官即時下指令，學員在第一人稱視角中操作。
